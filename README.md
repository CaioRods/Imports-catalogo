# IMPRTS — catálogo

Site da IMPRTS (iPhone, Mac e assistência técnica): landing + catálogo ligado em tempo real ao sistema da loja.
Estático (HTML/CSS/JS puro, sem build). Para rodar localmente: `python3 -m http.server 5173`.
